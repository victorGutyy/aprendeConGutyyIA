01 · Qué es el ML clásico

Tú dabas las reglas; ahora el modelo las descubre

Aprendizaje supervisado: aprender de ejemplos que ya traen su respuesta.

A

Característica (X)

El dato de entrada: una columna. Metros cuadrados, medidas de un pétalo.

B

Etiqueta (y)

La respuesta que queremos predecir: el precio, la especie.

C

Entrenar y predecir

fit ajusta el modelo a ejemplos resueltos; predict responde a casos nuevos.

Analogía · exámenes de años anteriores

Resuelves muchos exámenes viejos con las respuestas a la vista. El día del examen real se nota si aprendiste el patrón o solo memorizaste.

01 · Qué es el ML clásico

Regresión vs. clasificación

TipoLa respuesta es…Ejemplos
Regresiónun númeroprecio de una casa, temperatura, minutos de retraso
Clasificaciónuna categoríaspam o no spam, especie de flor, aprobado o reprobado
Y entonces… X

X es una matriz n_ejemplos × n_características (Semanas 7 y 9); y es un vector con una respuesta por ejemplo.

02 · Regresión

Regresión lineal: ajustar una recta

Es la neurona de la Semana 7 con un término extra: y ≈ w · x + b.

w

Coeficiente

Cuánto sube y por cada unidad de x.

b

Intercepto

El valor base cuando x es 0.

MSE

Error cuadrático medio

promedio((real − predicho)²): lo que el modelo minimiza.

Conexión · Semana 7

Con varias características, w · x es el producto punto. Minimizar el error es lo que hacía el descenso del gradiente.

02 · Regresión

Regresión lineal con scikit-learn

regresion.pypython
rng = np.random.default_rng(42)
m2 = rng.uniform(30, 120, size=100)
precio = 1500 * m2 + 20000 + rng.normal(0, 8000, size=100)

X = m2.reshape(-1, 1)   # scikit-learn exige X en 2D
modelo = LinearRegression().fit(X, precio)

print(modelo.coef_)        # [1506.8…] ≈ 1500
print(modelo.intercept_)   # 19385.2…  ≈ 20000
print(modelo.predict([[80]]))   # [139930.1…]
Resultadorecuperó la relación escondida (1500 y 20000) a pesar del ruido
Aprender

Los datos tenían ruido; el modelo igual encontró casi exactamente la recta que los generó.

03 · Clasificación

Clasificar: de la puntuación a la probabilidad

Regresión logística

Calcula una puntuación lineal w · x + b y la convierte en una probabilidad entre 0 y 1 (Semana 8). A pesar del nombre, es un clasificador.

Árbol de decisión

Una cadena de preguntas de sí/no hasta llegar a una respuesta, como el juego de las veinte preguntas.

Misma interfaz

Cambiar de modelo cuesta una línea: ambos son estimadores con fit, predict y score (POO de la Semana 6).

03 · Clasificación

El patrón fit → predict → score

estimador.pypython
modelo = LogisticRegression(max_iter=1000)  # o DecisionTreeClassifier()
modelo.fit(X_ent, y_ent)       # aprender
modelo.predict(X_nuevos)       # clase para cada fila
modelo.predict_proba(X_nuevos) # probabilidad de cada clase
modelo.score(X_prueba, y_prueba)  # exactitud (accuracy)
Estándar de facto

XGBoost, LightGBM y casi todas las librerías de ML imitan esta interfaz.

04 · Evaluar

Sobreajuste: memorizar no es aprender

↗

Sobreajuste

Memoriza el entrenamiento, ruido incluido. Nota alta en entrenamiento, peor en prueba.

↘

Subajuste

Modelo demasiado simple: falla incluso en entrenamiento.

✓

Buen ajuste

Notas parecidas en entrenamiento y prueba.

Ejemplo real de esta clase

Un árbol sin límite saca 1.0 en entrenamiento y 0.933 en prueba. La que cuenta es la de prueba.

04 · Evaluar

Métricas básicas

ProblemaMétricaQué mide
RegresiónMSE / RMSEError promedio (RMSE en unidades de y); menor es mejor
RegresiónR²Fracción de la variación que el modelo explica (1.0 = perfecto)
ClasificaciónExactitudPorcentaje de aciertos
ClasificaciónMatriz de confusiónQué clase real se confundió con cuál
Cuidado

Si solo el 1 % de los correos son fraude, decir siempre «no es fraude» acierta el 99 % y no sirve de nada.

05 · Pipeline

Preprocesar sin hacer trampa

La media y la desviación del escalado deben calcularse solo con el entrenamiento. Si usas los datos de prueba, hay fuga de datos y la métrica sale falsamente optimista.

pipeline.pypython
modelo = make_pipeline(
    StandardScaler(),                    # normalización (Semana 8)
    LogisticRegression(max_iter=1000),
)
modelo.fit(X_ent, y_ent)   # aprende solo de X_ent
modelo.score(X_prueba, y_prueba)
Garantía

El Pipeline aprende todo en fit y solo aplica lo aprendido en predict.

06 · IA/ML

Por qué esto importa para IA/ML

A

El flujo de todo proyecto

Datos → X/y → dividir → entrenar → evaluar → predecir. Las redes neuronales siguen igual.

B

Línea base obligatoria

En datos tabulares igualan o superan a modelos complejos: rápidos, baratos e interpretables.

C

Ladrillo del Deep Learning

Una neurona es una puntuación lineal más una activación; una red las apila.

D

Disciplina de evaluación

Probar con datos no vistos y desconfiar de la nota de entrenamiento.

E

Patrón estándar

fit/predict lo imitan XGBoost, LightGBM y más.

07 · Ejemplo práctico

Del pseudocódigo a scikit-learn

analisis_flores.pypython
def dividir(X, y, semilla=42):
    return train_test_split(
        X, y, test_size=0.2, random_state=semilla, stratify=y)

def crear_modelo():
    """Escalado + regresión logística (evita fugas de datos)."""
    return make_pipeline(StandardScaler(),
                         LogisticRegression(max_iter=1000))

def evaluar(modelo, X_prueba, y_prueba):
    pred = modelo.predict(X_prueba)
    return (accuracy_score(y_prueba, pred),
            confusion_matrix(y_prueba, pred))
Resultadoexactitud en prueba: 0.933
Diseño

Funciones pequeñas con una sola responsabilidad (Semana 3), fáciles de probar (Semana 6).

09 · Errores comunes

Errores comunes de principiante

  • Evaluar con los datos de entrenamiento.
  • Escalar o limpiar antes de dividir (fuga de datos).
  • Olvidar reshape(-1, 1) con una sola característica.
  • Fiarse de la exactitud con clases desbalanceadas.
  • No fijar random_state.
  • Confundir regresión con clasificación.
  • Leer predict_proba como certeza.
  • Empezar con un modelo sofisticado sin línea base simple.
