02 · Resumir datos

Media y mediana

Analogía · el sueldo del barrio

Cinco vecinos ganan [1, 2, 3, 4, 1000] (miles). ¿Cuál es el sueldo típico?

estadistica.pypython
def media(valores: list[float]) -> float:
    """Promedio: suma dividida por cuántos hay."""
    if not valores:
        raise ValueError("La lista no puede estar vacía")
    return sum(valores) / len(valores)


def mediana(valores: list[float]) -> float:
    """Valor del medio una vez ordenados."""
    if not valores:
        raise ValueError("La lista no puede estar vacía")
    ordenados = sorted(valores)   # no altera la original
    n = len(ordenados)
    medio = n // 2
    if n % 2 == 1:
        return ordenados[medio]
    return (ordenados[medio - 1] + ordenados[medio]) / 2

02 · Resumir datos

Desviación estándar: cuán dispersos están

Dos grupos pueden tener media 10 y ser muy distintos: [10, 10, 10] y [2, 10, 18].

estadistica.pypython
import math


def desviacion_estandar(valores: list[float]) -> float:
    """Distancia típica de los valores respecto a su media."""
    m = media(valores)
    # Al cuadrado: negativos y positivos no se cancelan.
    varianza = sum((x - m) ** 2 for x in valores) / len(valores)
    return math.sqrt(varianza)   # vuelve a las unidades originales
Resultado[10,10,10] → 0.0 · [2,10,18] → 6.532
Conexión con la Semana 7

El error cuadrático medio que minimizaste con descenso del gradiente es una varianza de los errores.

03 · Probabilidad

Probabilidad: medir lo incierto

Analogía · el dado

Un número entre 0 (imposible) y 1 (seguro). P(evento) = favorables / posibles.

1

Dado

P(sacar 6) = 1/6 ≈ 0.1667

2

Complemento

P(no ocurre) = 1 − P(ocurre)

3

Independientes

P(A y B) = P(A) · P(B)

04 · Simulación

Simular en vez de calcular

Repite el experimento muchas veces con números aleatorios y cuenta (Monte Carlo).

simulacion.pypython
import random


def probabilidad_simulada(evento, repeticiones: int = 100_000, semilla: int = 42) -> float:
    """Estima P(evento) repitiendo un experimento muchas veces."""
    azar = random.Random(semilla)   # semilla: resultados reproducibles
    exitos = sum(1 for _ in range(repeticiones) if evento(azar))
    return exitos / repeticiones


# ¿Probabilidad de sacar un 6? (teoría: 1/6 ≈ 0.1667)
probabilidad_simulada(lambda azar: azar.randint(1, 6) == 6)
Resultado≈ 0.1687 (teoría: 0.1667)
Semilla

Con semilla=42 el «azar» es repetible. Fijar semillas es obligatorio para la reproducibilidad.

05 · Condicional y Bayes

Probabilidad condicional y teorema de Bayes

Analogía · el detective

Empiezas con una sospecha y la ajustas con cada pista. P(A | B): probabilidad de A dado B.

P(clase | pista) = P(pista | clase) · P(clase) / P(pista)

Convierte lo que sabes en lo que quieres saber.

05 · Condicional y Bayes

Ejemplo: filtro de spam

40 % del correo es spam. «gratis» aparece en 50 % del spam y en 5 % del correo legítimo. Llega un correo con «gratis»…

bayes.pypython
def bayes(p_clase: float, p_pista_dada_clase: float, p_pista_dada_otra: float) -> float:
    """P(clase | pista) por el teorema de Bayes, con dos clases."""
    numerador = p_pista_dada_clase * p_clase
    # P(pista) = suma de ambos caminos posibles
    total = numerador + p_pista_dada_otra * (1 - p_clase)
    return numerador / total


bayes(p_clase=0.4, p_pista_dada_clase=0.5, p_pista_dada_otra=0.05)
Resultado0.8696 → de 40 % a 87 % con una sola pista

Un clasificador Naive Bayes hace esto con cientos de palabras (Módulo 10).

07 · Ejemplo práctico

¿Al menos un 6 en 4 tiradas?

Pseudocódigo primero, código después.

pseudocodigo.txtpseudocódigo
repetir N veces:
    tirar un dado 4 veces
    si alguna salió 6: contar un éxito
mostrar éxitos / N
comparar con 1 − (5/6)^4
Teoría

Por el complemento: 1 − (5/6)⁴ ≈ 0.5177. Verificaremos por simulación.

07 · Ejemplo práctico

Del pseudocódigo a Python

ejemplo.pypython
def al_menos_un_seis(azar) -> bool:
    return any(azar.randint(1, 6) == 6 for _ in range(4))   # corta al primer True


simulada = probabilidad_simulada(al_menos_un_seis)
teorica = 1 - (5 / 6) ** 4
print(round(simulada, 4), round(teorica, 4))

07 · Ejemplo práctico

Pruebas con pytest

test_estadistica.pypython
import pytest
from estadistica import media, mediana, desviacion_estandar, probabilidad_simulada, bayes


def test_mediana_resiste_extremos():
    assert mediana([1, 2, 3, 4, 1000]) == 3
    assert media([1, 2, 3, 4, 1000]) == 202


def test_desviacion():
    assert desviacion_estandar([2, 4, 4, 4, 5, 5, 7, 9]) == pytest.approx(2.0)


def test_lista_vacia():
    with pytest.raises(ValueError):
        media([])


def test_simulacion_dado():
    p = probabilidad_simulada(lambda azar: azar.randint(1, 6) == 6)
    assert p == pytest.approx(1 / 6, abs=0.01)


def test_bayes():
    assert bayes(0.4, 0.5, 0.05) == pytest.approx(0.2 / (0.2 + 0.03))

09 · Errores comunes

Errores comunes de principiante

  • Usar la media con datos atípicos sin mirar la mediana.
  • Dividir entre len(valores) sin comprobar lista vacía.
  • La falacia del apostador: los eventos independientes no tienen memoria.
  • Olvidar la semilla y no poder reproducir un resultado.
  • Confundir P(A | B) con P(B | A).
  • Evaluar un modelo con los mismos datos de entrenamiento.
