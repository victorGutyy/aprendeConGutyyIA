02 · Vectores

Vectores: una lista de características

Analogía · la ficha de un jugador

[goles, asistencias, minutos]: una lista ordenada donde la posición tiene significado.

vectores.pypython
jugador_a = [12, 5, 2700]
jugador_b = [3, 9, 1800]

# Suma: posición con posición
suma = [x + y for x, y in zip(jugador_a, jugador_b)]
# Escalar: multiplicar cada posición
doble = [2 * x for x in jugador_a]
Resultadosuma = [15, 14, 4500] · doble = [24, 10, 5400]

En ML cada dato es un vector: una casa, una imagen, incluso una palabra (un embedding).

03 · Producto punto

El producto punto: dos vectores, un número

Analogía · la cuenta del súper

Compras [2, 1, 3] unidades a precios [4.0, 0.5, 2.0]: 2·4.0 + 1·0.5 + 3·2.0 = 14.5.

algebra.pypython
def producto_punto(a: list[float], b: list[float]) -> float:
    """Suma de multiplicar componente a componente."""
    if len(a) != len(b):
        # Fallar rápido: un error claro vale más que un resultado silenciosamente erróneo.
        raise ValueError("Los vectores deben tener la misma longitud")
    return sum(x * y for x, y in zip(a, b))
Resultadoproducto_punto([2, 1, 3], [4.0, 0.5, 2.0]) → 14.5

03 · Producto punto

Qué mide el producto punto

Mide cuánto «coinciden» dos vectores.

CasoEjemploResultado
Misma dirección[1,2,3] · [2,4,6]28 (grande)
Perpendiculares[1,2,3] · [3,0,-1]0
Opuestos[1,2,3] · [-1,-2,-3]-14 (negativo)
En ML

Una neurona calcula entradas · pesos; un buscador compara textos con el producto punto normalizado (similitud coseno).

04 · Matrices

Matrices: una tabla de números

Una matriz es una lista de filas; cada fila es un vector. El producto matriz-vector hace un producto punto de cada fila con el vector.

algebra.pypython
matriz = [[2, 1],
          [0, 3]]

def matriz_por_vector(matriz, v):
    return [producto_punto(fila, v) for fila in matriz]

print(matriz_por_vector(matriz, [1, 2]))
Resultado[4, 6] ← fila 1: 2·1+1·2 = 4 · fila 2: 0·1+3·2 = 6
En ML

Una capa de red neuronal es una matriz de pesos; aplicarla a un dato es esta operación. Costo: O(m·n) (Semana 5).

05 · Cálculo

La derivada: la pendiente en un punto

Analogía · la ladera de una montaña

La pendiente te dice qué tan empinado es el suelo justo donde estás y hacia dónde sube.

DerivadaLa función…
Positivasube al avanzar a la derecha
Negativabaja
Ceropunto plano: cima o valle

05 · Cálculo

Aproximar la derivada en código

algebra.pypython
def derivada_numerica(f, x: float, h: float = 1e-6) -> float:
    """Pendiente aproximada de f en x (diferencia central)."""
    return (f(x + h) - f(x - h)) / (2 * h)

print(round(derivada_numerica(lambda x: x ** 2, 3), 4))
Resultado6.0 ← la regla 2x da 2·3 = 6

Se mide la pendiente entre dos puntos muy cercanos. Nótese que se pasa una función como argumento: en Python las funciones también son valores.

06 · Descenso del gradiente

Descenso del gradiente: bajar el cerro con niebla

Analogía

No ves el valle, pero sientes la pendiente. Da un paso pequeño contra la pendiente y repite.

algebra.pypython
def descenso_gradiente(f, x_inicial, tasa=0.1, pasos=50):
    x = x_inicial
    for _ in range(pasos):
        x = x - tasa * derivada_numerica(f, x)
    return x

error = lambda x: (x - 3) ** 2   # mínimo en x = 3
print(round(descenso_gradiente(error, 0), 4))
Resultado3.0
0→0.6→1.08→1.464→1.771→3

06 · Descenso del gradiente

La tasa de aprendizaje

MUY PEQUEÑA

Lento

Avanza con seguridad pero necesita muchísimos pasos.

ADECUADA

Converge

Pasos que se acortan solos al acercarse al valle.

MUY GRANDE

Diverge

Se pasa de largo y rebota cada vez más lejos.

Regla

x_nuevo = x - tasa * derivada(x). Elegir bien la tasa es una de las decisiones más prácticas del ML.

07 · Para IA/ML

Por qué esto importa para IA/ML

  1. 01

    Entrenar = minimizar un error. Se define qué tan mal predice el modelo y se baja esa montaña.

  2. 02

    Pesos = vectores y matrices. Predecir es producto punto / matriz-vector.

  3. 03

    Muchas dimensiones. Con millones de pesos el gradiente es un vector (una derivada por peso); PyTorch lo calcula solo (Semana 11).

08 · Ejemplo práctico

Una neurona que aprende un peso

Datos (1,2), (2,4), (3,6). Objetivo: hallar w tal que salida ≈ w · entrada.

pseudocodigopython
w ← 0
repetir 100 veces:
    para cada ejemplo (x, y): error = w·x − y
    gradiente ← promedio de 2 · error · x
    w ← w − tasa · gradiente
mostrar w

08 · Ejemplo práctico

Del pseudocódigo al código real

neurona.pypython
datos = [(1, 2), (2, 4), (3, 6)]   # (entrada, salida esperada)
w = 0.0                            # el peso que debe aprender el modelo
tasa = 0.05

for _ in range(100):
    # Derivada del error cuadrático medio respecto a w
    gradiente = sum(2 * (w * x - y) * x for x, y in datos) / len(datos)
    w = w - tasa * gradiente

print(round(w, 4))
Resultado2.0 ← el modelo descubrió: salida = 2 · entrada
Esto es entrenar

Datos, un parámetro, una medida de error y descenso del gradiente. El Deep Learning es una versión más grande del mismo bucle.

08 · Ejemplo práctico

Pruebas con pytest

test_algebra.pypython
import pytest
from algebra import producto_punto, matriz_por_vector, derivada_numerica

def test_producto_punto():
    assert producto_punto([1, 2, 3], [4, 5, 6]) == 32

def test_longitudes_distintas():
    with pytest.raises(ValueError):
        producto_punto([1, 2], [1, 2, 3])

def test_derivada():
    # Con decimales nunca se compara con ==
    assert derivada_numerica(lambda x: x ** 2, 3) == pytest.approx(6, abs=1e-4)
Resultado5 passed

10 · Antes de seguir

Errores comunes de principiante

  1. 01

11 · Practica

Ejercicio propuesto: similitud coseno

Escribe similitud_coseno(a, b) = producto_punto(a, b) / (norma(a) * norma(b)), con norma(v) = raíz de producto_punto(v, v) (usa math.sqrt). Debe dar 1.0 para [1,2,3] y [2,4,6], y 0.0 para [1,2,3] y [3,0,-1].

Autoevaluación

01¿Qué es un vector en ML?

RespuestaUna lista ordenada de números donde cada posición tiene significado; cada dato suele ser un vector de características.

02Producto punto de [1,2,3] y [4,5,6]

Respuesta1·4 + 2·5 + 3·6 = 32.

03¿Qué mide intuitivamente el producto punto?

RespuestaCuánto coinciden en dirección: grande si apuntan igual, 0 si son perpendiculares, negativo si son opuestos.

04¿Qué hace el producto matriz-vector?

RespuestaProducto punto de cada fila con el vector; junta los resultados en un vector nuevo.

05¿Qué indica el signo de la derivada?

RespuestaPositiva: sube; negativa: baja; cero: punto plano (cima o valle).

Cierre · Parte 2 de 2

Autoevaluación (continuación)

06¿Por qué se resta la derivada en el descenso del gradiente?

RespuestaPara moverse contra la pendiente, hacia donde la función baja.

07¿Y si la tasa de aprendizaje es demasiado grande?

RespuestaSe pasa del mínimo y el valor oscila o diverge.

08V/F: «zip lanza error si las longitudes difieren».

RespuestaFalso; corta al más corto sin avisar. Por eso se valida explícitamente.

09Sin jerga: ¿qué es «entrenar» un modelo?

RespuestaAjustar números (pesos) una y otra vez, bajando por una medida de error, hasta que las predicciones coincidan con los ejemplos.
