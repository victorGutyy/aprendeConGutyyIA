01 · Listas

La estructura que ya usabas, ahora a fondo

Una lista es una fila numerada de casilleros: cada valor tiene una posición (índice), empezando en 0.

indices.pypython
frutas = ["manzana", "pera", "uva"]

print(frutas[0])    # manzana — índice 0
print(frutas[-1])   # uva — último elemento
print(frutas[1:3])  # ['pera', 'uva'] — slicing
Analogía · el tren con vagones numerados

Cada vagón tiene un número desde la locomotora (0, 1, 2…), pero también se cuenta desde el final (-1 es el último). El slicing es "del vagón 1 al 2, sin incluir el 3" — igual que range() de la Semana 3.

Modificar una lista

Los métodos más usados

MétodoQué haceAnalogía
.append(x)agrega x al finalSubir un vagón nuevo al final del tren.
.insert(i, x)inserta x en la posición iMeter un vagón entre dos existentes.
.remove(x)quita la primera aparición de xDesenganchar el primer vagón con ese nombre.
.pop(i)quita y devuelve el elemento en iDesenganchar un vagón y quedarte con él.

Punto de confusión clásico

.sort() modifica la lista original y devuelve None. Para conservar el original y obtener una lista nueva ordenada, se usa sorted(lista).

Construir listas en una línea

List comprehensions

El mismo for + if de siempre, expresado en una sola línea.

comprehension.pypython
numeros = [4, 8, -3, 10, -7]

# Con for tradicional (Semana 3):
positivos = []
for n in numeros:
    if n > 0:
        positivos.append(n)

# La misma idea como list comprehension:
positivos = [n for n in numeros if n > 0]
print(positivos)   # [4, 8, 10]

02 · Diccionarios

Buscar por nombre, no por posición

Un diccionario es una colección de pares clave: valor — se busca por nombre, no por posición.

Analogía · la agenda de contactos

No buscas a alguien por "la persona número 47" — buscas por su nombre (la clave) y el teléfono aparece (el valor).

estudiante.pypython
estudiante = {
    "nombre": "Ana",
    "edad": 21,
    "ciudad": "Bogotá",
}

print(estudiante["nombre"])   # Ana
estudiante["edad"] = 22        # actualiza un valor existente
estudiante["carrera"] = "Ingeniería"   # agrega una clave nueva

Acceso seguro y recorrido

.get(), .items(), .keys()

Acceder con [] a una clave inexistente produce KeyError. .get() nunca falla.

get_items.pypython
print(estudiante.get("telefono"))              # None — no existe, no falla
print(estudiante.get("telefono", "sin dato"))  # "sin dato"

for clave, valor in estudiante.items():
    print(f"{clave}: {valor}")

03 · Tuplas

Cuando los datos no deben cambiar

Se escriben con () en vez de [], y son inmutables: una vez creadas, no cambian.

tupla.pypython
coordenada = (4.7110, -74.0721)   # latitud, longitud
print(coordenada[0])               # 4.711

coordenada[0] = 0   # ERROR: TypeError — no se puede modificar
Analogía · la fecha de nacimiento

Una lista es una lista de tareas: se espera que cambie. Una tupla es como una fecha de nacimiento: un dato que, por naturaleza, no debería cambiar nunca.

Conectando con la Semana 3

Tuple unpacking: ya lo usabas sin saberlo

return promedio, aprobado de la Semana 3 construye literalmente una tupla.

unpacking.pypython
def evaluar_promedio(notas):
    promedio = sum(notas) / len(notas)
    aprobado = promedio >= 6.0
    return promedio, aprobado   # construye la tupla

resultado = evaluar_promedio([8.5, 7.0, 9.0])
print(type(resultado))    # <class 'tuple'>

promedio, aprobado = resultado   # desempaquetado

a, b = 1, 2
a, b = b, a       # intercambio directo, sin variable auxiliar

04 · Conjuntos

Sin duplicados, sin orden garantizado

Un set guarda valores únicos — agregar un valor repetido simplemente no hace nada.

Analogía · la lista de invitados

Si alguien anota el mismo nombre dos veces, en la lista real esa persona cuenta una sola vez. Un conjunto hace esa limpieza automáticamente.

duplicados.pypython
colores = ["rojo", "azul", "rojo", "verde", "azul"]
unicos = set(colores)
print(unicos)          # {'rojo', 'azul', 'verde'}
print(len(unicos))     # 3

Unión, intersección, diferencia

Operaciones de conjuntos

|

Unión

Todos los elementos de ambos conjuntos, sin repetir.

&

Intersección

Solo los elementos que están en ambos a la vez.

-

Diferencia

Elementos que están en uno pero no en el otro.

conjuntos.pypython
salon_a = {"Ana", "Luis", "Marta"}
salon_b = {"Marta", "Pedro", "Ana"}

print(salon_a | salon_b)   # unión: todos, sin repetir
print(salon_a & salon_b)   # intersección: {'Ana', 'Marta'}
print(salon_a - salon_b)   # diferencia: {'Luis'}

"¿Buscas por clave? dict. ¿Orden y repeticiones que pueden cambiar? list. ¿Datos que van juntos y no cambian? tuple. ¿Solo presencia, sin repetidos? set."

Mirando adelante · IA y Machine Learning

Por qué esto importa para IA/ML

Un DataFrame de pandas es esto

Conceptualmente, un diccionario donde cada clave es una columna y cada valor es la lista de datos de esa columna: {"nombre": [...], "edad": [...]}.

Un batch de entrenamiento suele ser una lista de tuplas (entrada, etiqueta). El vocabulario de un modelo de lenguaje se construye pasando el texto por un set para quedarse solo con palabras únicas. Las coordenadas de un embedding se manejan como posiciones fijas, nunca como algo que se reordena a mitad de un cálculo.

06 · Ejemplo práctico

Del pseudocódigo al código real

carrito.pypython
carrito = [
    ("laptop", 3200000, "tecnología"),
    ("mouse", 45000, "tecnología"),
    ("cuaderno", 8000, "papelería"),
    ("audífonos", 120000, "tecnología"),
]

total = 0
for nombre, precio, categoria in carrito:   # tuple unpacking
    total = total + precio

producto_mas_caro = max(carrito, key=lambda p: p[1])
categorias = {categoria for _, _, categoria in carrito}

print(f"Total: ${total:,}")
print(f"Más caro: {producto_mas_caro[0]}")
ResultadoTotal: $3,373,000 · Más caro: laptop
Punto de confusión clásico

_ no es magia especial — es solo una variable normal, usada por convención cuando su valor no se va a usar.

Autoevaluación

01¿Qué diferencia hay entre frutas[1] y frutas[1:3]?

Respuestafrutas[1] devuelve un elemento; frutas[1:3] devuelve una lista nueva (slicing) desde el índice 1 hasta antes del 3.

02¿Qué hace .pop() que no hace .remove()?

Respuesta.pop() quita por posición y devuelve el valor; .remove() quita por valor y no devuelve nada útil.

03¿Por qué .get() es más seguro que []?

RespuestaSi la clave no existe, .get() devuelve None (o un valor por defecto) en vez de lanzar KeyError.

04¿Qué significa que una tupla sea inmutable?

RespuestaQue una vez creada, no se puede agregar, quitar ni reemplazar ninguno de sus elementos.

05¿Qué tipo de dato devuelve realmente evaluar_promedio con return promedio, aprobado?

RespuestaUna tupla de dos valores, que luego se desempaqueta en dos variables.
