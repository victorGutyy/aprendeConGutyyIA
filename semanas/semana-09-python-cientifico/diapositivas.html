01 · Por qué existen

Python puro llega a su límite

Un bucle sobre un millón de números es lento, y reescribir la media a mano cansa.

A

NumPy

Arreglos numéricos rápidos de N dimensiones: los vectores y matrices de la Semana 7.

B

Pandas

Tablas con columnas con nombre: un diccionario de listas (Semana 4) con superpoderes.

Matplotlib

Convierte números en imágenes para entenderlos y comunicarlos.

Analogía · cocina industrial

Con Python puro cocinas plato por plato. NumPy es una línea de producción: la misma operación sobre toda la bandeja a la vez. Pandas es el cuaderno de pedidos; Matplotlib, la vitrina.

02 · NumPy

Del vector al ndarray

numpy_basico.pypython
import numpy as np

sueldos = np.array([1, 2, 3, 4, 1000])

print(sueldos.shape)        # (5,)   → forma
print(sueldos.dtype)        # int64  → un solo tipo
print(sueldos.mean())       # 202.0  → media de la Semana 8
print(np.median(sueldos))   # 3.0
print(sueldos * 2)          # [2 4 6 8 2000] → ¡sin bucle!
Ojo

[1, 2, 3] * 2 repite la lista; np.array([1, 2, 3]) * 2 multiplica cada elemento.

02 · NumPy

Vectorización: el bucle se hace por dentro

Escribes la operación sobre el arreglo completo; NumPy ejecuta el bucle en código compilado.

vectorizar.pypython
rng = np.random.default_rng(42)   # semilla (Semana 8)
x = rng.random(1_000_000)

# Con bucle de Python:
lento = sum(v * v for v in x.tolist())
# Vectorizado (producto punto consigo mismo):
rapido = float(np.dot(x, x))
Resultadoambos → 333336.885… · vectorizado: más de 10× más rápido
Regla práctica

Si escribes un for sobre un arreglo de NumPy, probablemente exista una forma vectorizada.

02 · NumPy

Matrices, ejes y producto punto

matrices.pypython
m = np.array([[1, 2, 3],
              [4, 5, 6]])      # matriz 2×3

print(m.shape)         # (2, 3)
print(m.sum(axis=0))   # [5 7 9]  → una suma por columna
print(m.sum(axis=1))   # [ 6 15]  → una suma por fila

a = np.array([1, 2, 3]); b = np.array([4, 5, 6])
print(a @ b)           # 32 → producto punto (Semana 7)
Truco para el axis

axis=0 colapsa las filas (queda una entrada por columna); axis=1 colapsa las columnas.

Filtrar y operar arreglos de distinta forma

broadcasting.pypython
notas = np.array([[7, 8],
                  [5, 6],
                  [9, 10]])

# [[ 0.  0.]
#  [-2. -2.]
#  [ 2.  2.]]
Normalizar en una línea

Con broadcasting, la normalización de la Semana 8 es (v - v.mean()) / v.std().

03 · Pandas

Pandas: tablas con nombre

Un DataFrame tiene filas, columnas con nombre y un tipo por columna. Por dentro, cada columna es un arreglo de NumPy.

dataframe.pypython
import pandas as pd

df = pd.DataFrame({
    "producto": ["pan", "leche", "pan", "queso",
                 "leche", "pan", "queso", "leche"],
    "tienda":   ["A", "A", "B", "B", "A", "A", "B", "B"],
    "unidades": [10, 4, 7, 2, 5, 12, 3, None],   # None → faltante
    "precio":   [1.5, 2.0, 1.5, 8.0, 2.0, 1.5, 8.0, 2.0],

03 · Pandas

groupby: separar → aplicar → combinar

groupby.pypython
por_producto = (df.groupby("producto")["total"]
                  .sum()
                  .sort_values(ascending=False))
print(por_producto)
Resultadopan 43.5 · queso 40.0 · leche 28.0

2

06 · Ejemplo práctico

Análisis de ventas de una tienda

Pseudocódigo primero, código después.

pseudocodigo.txtpseudocódigo
cargar la tabla de ventas
rellenar las unidades faltantes con la mediana
total de cada venta = unidades × precio
sumar los totales agrupando por producto
ordenar de mayor a menor
dibujar un gráfico de barras con título y etiquetas
Diseño

Cuatro funciones pequeñas, cada una con una sola responsabilidad (Semana 3): cargar_ventas, limpiar, ventas_por_producto, graficar.

06 · Ejemplo práctico

Del pseudocódigo a Python

analisis_ventas.pypython
def limpiar(df: pd.DataFrame) -> pd.DataFrame:
    """Copia con 'unidades' rellenadas con la mediana."""
    limpio = df.copy()   # no mutar el original
    limpio["unidades"] = limpio["unidades"].fillna(
        limpio["unidades"].median())
    return limpio


def ventas_por_producto(df: pd.DataFrame) -> pd.Series:
    total = df["unidades"] * df["precio"]
    return (total.groupby(df["producto"])
                 .sum().sort_values(ascending=False))
Resultadopan 43.5 · queso 40.0 · leche 28.0 → ventas.png
Decisión de ingeniería

limpiar devuelve una copia: así los datos originales no cambian por sorpresa (Semana 6).

Pruebas con pytest

test_analisis_ventas.pypython
def test_limpiar_rellena_con_la_mediana():
    limpio = limpiar(cargar_ventas())
    assert limpio["unidades"].isna().sum() == 0
    assert limpio["unidades"].iloc[-1] == 5


def test_limpiar_no_modifica_el_original():
    original = cargar_ventas()
    limpiar(original)
    assert original["unidades"].isna().sum() == 1


def test_ventas_por_producto():
    totales = ventas_por_producto(limpiar(cargar_ventas()))
    assert totales.index[0] == "pan"
    assert totales["pan"] == pytest.approx(43.5)

08 · Errores comunes

Errores comunes de principiante

  • Escribir un for donde basta vectorizar.
  • Confundir lista * 2 con arreglo * 2.
  • Confundir axis=0 con axis=1.
  • Calcular sin revisar valores faltantes.
  • Modificar el DataFrame original dentro de una función.
  • Usar inplace=True o asignaciones encadenadas.
  • Publicar un gráfico sin título, ejes ni unidades.
  • Olvidar plt.close(fig) en bucles de gráficos.
