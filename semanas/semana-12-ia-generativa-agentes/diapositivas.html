01 · LLM

Un LLM es una red que predice el siguiente token

La misma idea de la Semana 11, escalada a miles de millones de pesos. Analogía: el autocompletado del teléfono que leyó una biblioteca entera.

1 texto→2 tokens→3 red profunda→4 probabilidades→5 siguiente token

01 · LLM

Cuatro ideas clave

TOKEN

Token

Trozo de texto que el modelo lee y escribe.

CONTEXTO

Ventana de contexto

Lo que no cabe, el modelo no lo ve.

AZAR

Temperatura

Baja = predecible; alta = variada (Semana 8).

01 · LLM

Plausible no es lo mismo que verdadero

Alucinación

El modelo puede inventar datos con total aplomo. Por eso existen RAG, verificación y pruebas.

Tú casi nunca entrenas un LLM: lo usas por API o lo ejecutas ya entrenado.

04 · RAG

RAG: examen a libro abierto

1 Recuperar fragmentos→2 Aumentar el prompt→3 Generar la respuesta

El modelo no memoriza tus documentos: busca la página correcta y responde con ella delante.

04 · RAG

Parecido = similitud coseno de embeddings

Un embedding es un vector que representa el significado de un texto. Textos parecidos quedan cerca, y la cercanía se mide con el producto punto de la Semana 7.

Realidad

Los sistemas reales usan un modelo de embeddings y una base vectorial; hoy usamos una bolsa de palabras de juguete.

05 · Agentes

Un agente es un LLM dentro de un bucle

1 Observar→2 Decidir→3 Usar herramienta→4 Ver resultado→5 Repetir o responder

Analogía: un asistente con teléfono y calculadora. No sabe todo, pero sabe cuándo usar cada herramienta.

05 · Agentes

Reglas de diseño de un agente seguro

  1. 01

    El modelo propone, tu código ejecuta y valida.

  2. 02

    Lista cerrada de herramientas y permisos mínimos.

  3. 03

    Tope de pasos y confirmación humana en acciones irreversibles.

  4. 04

    Contenido externo = datos, no órdenes (inyección de prompt).

07 · Ejemplo práctico

RAG mínimo: de texto a vectores

rag_minimo.py (1/2)Python
def tokenizar(texto):
    return re.findall(r"\w+", texto.lower())

def vectorizar(texto):
    # "Embedding" de juguete: cuántas veces aparece cada palabra (bolsa de palabras).
    return Counter(tokenizar(texto))

def similitud_coseno(a, b):
    # Mismo producto punto de la Semana 7, sobre diccionarios dispersos.
    punto = sum(a[p] * b[p] for p in a if p in b)
    norma = math.sqrt(sum(v * v for v in a.values())) * math.sqrt(sum(v * v for v in b.values()))
    return punto / norma if norma else 0.0

07 · Ejemplo práctico

RAG mínimo: recuperar y armar el prompt

rag_minimo.py (2/2)Python
def recuperar(pregunta, documentos, k=2):
    q = vectorizar(pregunta)
    puntuados = [(similitud_coseno(q, vectorizar(d)), d) for d in documentos]
    puntuados.sort(key=lambda par: par[0], reverse=True)
    return [d for s, d in puntuados[:k] if s > 0]

def construir_prompt(pregunta, fragmentos):
    contexto = "\n".join(f"- {f}" for f in fragmentos) or "(sin contexto)"
    return (
        "Responde SOLO con el contexto. Si no alcanza, di que no lo sabes.\n"
        f"Contexto:\n{contexto}\n\nPregunta: {pregunta}"
    )

08 · Segundo ejemplo

Agente con herramientas

agente.pyPython
HERRAMIENTAS = {"sumar": sumar}   # lista cerrada: el agente solo puede llamar lo que registres

def ejecutar_agente(llm, pregunta, max_pasos=5):
    """`llm` es cualquier función mensajes -> dict. Así se prueba sin red ni claves."""
    mensajes = [{"role": "user", "content": pregunta}]
    for _ in range(max_pasos):                      # tope de pasos: evita bucles infinitos
        decision = llm(mensajes)
        if decision["tipo"] == "respuesta":
            return decision["texto"]
        nombre, args = decision["herramienta"], decision["args"]
        if nombre not in HERRAMIENTAS:
            resultado = f"error: herramienta desconocida &#x27;{nombre}'"
        else:
            resultado = HERRAMIENTAS[nombre](**args)
        mensajes.append({"role": "tool", "content": json.dumps({"resultado": resultado})})
    return "No pude terminar dentro del límite de pasos."
ResultadoLa suma es 5.

10 · Vigencia técnica

Notas de vigencia (2026)

  1. 01

    Los modelos cambian rápido: nombres en configuración, no fijos en el código.

  2. 02

    Contextos largos no eliminan RAG.

  3. 03

    Salida estructurada y llamada a herramientas ya son nativas; MCP estandariza herramientas.

  4. 04

    Frameworks de agentes evolucionan: entiende el bucle primero.

  5. 05

    Modelos abiertos locales cuando importa la privacidad o el costo.

Autoevaluación (2/2)

6.¿Qué mide la similitud coseno entre embeddings?
Resp.Qué tan parecido es el significado (cercanía de vectores).

Resp.El agente repite el bucle decidir → herramienta → observar.
