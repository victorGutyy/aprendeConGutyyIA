01 · Decisiones compuestas

Combinar condiciones: and, or, not

La regla de una alberca pública: "puedes entrar si sabes nadar Y tienes más de 8 años, O si vienes acompañado de un adulto." Eso es exactamente lógica compuesta.

OperadorSe cumple cuando…Analogía
andambas condiciones son verdaderasLlave Y código para una caja fuerte de doble seguridad.
oral menos una condición es verdaderaPagar con tarjeta O efectivo: cualquiera sirve.
notinvierte el valor de una condiciónUn interruptor que voltea True a False.
alberca.pypython
sabe_nadar = True
edad = 6
acompanado_de_adulto = True

puede_entrar = (sabe_nadar and edad > 8) or acompanado_de_adulto
print(puede_entrar)   # True — va acompañado, aunque tenga 6 años

Precedencia y anidamiento

Paréntesis explícitos y condicionales anidados

and se evalúa antes que or, igual que * antes que +. Usar paréntesis no es opcional cuando la regla combina ambos.

retiro.pypython
if tiene_cuenta:
    if saldo >= 100:
        print("Retiro autorizado")
    else:
        print("Saldo insuficiente")
else:
    print("Primero debes abrir una cuenta")
Cuándo anidar en vez de usar and

Cuando cada nivel necesita su propia rama de "si no" — aquí "sin cuenta" y "con cuenta pero saldo insuficiente" son mensajes distintos, no uno solo.

02 · Repetición sin lista previa

range(): generar una secuencia de números

La Semana 1 recorría listas ya existentes. Cuando solo hace falta repetir N veces, range() genera la secuencia sin escribirla a mano.

range_ejemplos.pypython
for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):     # 1, 2, 3, 4, 5 (sin incluir el 6)
    print(i)

for i in range(0, 10, 2):  # 0, 2, 4, 6, 8 (de 2 en 2)
    print(i)

Control fino del bucle

break y continue

break

Corta el bucle por completo

Como salir de una fila antes de tiempo porque ya encontraste lo que buscabas.

continue

Salta solo la vuelta actual

Como saltarte un plato que no te gusta en un bufet, sin dejar de recorrer el resto.

Válido en ambos

for y while

No son exclusivos de un tipo de bucle; funcionan igual en los dos.

break_continue.pypython
numeros = [4, 8, -3, 10, -7]

# break: buscar el primer número negativo
for n in numeros:
    if n < 0:
        print(f"Encontrado: {n}")
        break

# continue: sumar solo los positivos, sin if/else
suma = 0
for n in numeros:
    if n < 0:
        continue
    suma = suma + n
print(f"Suma de positivos: {suma}")   # 22

03 · Funciones

Dejar de copiar y pegar código

Si quisieras el IMC de tres personas, copiarías la fórmula tres veces. Una función evita exactamente esa repetición.

Analogía · la receta con nombre propio

En vez de reescribir "pelar, cortar y licuar" cada vez, el menú dice "Jugo de mango". Llamar a una función es pedir "Jugo de mango"; la función es la receta completa detrás del nombre.

"Encapsular una tarea repetida en un solo lugar, con un nombre — la razón número uno de ingeniería de software para crear una función."

def, parámetros, return

Anatomía de una función

imc.pypython
def calcular_imc(peso, estatura):
    """Calcula el IMC a partir del peso (kg) y la estatura (m)."""
    imc = peso / (estatura ** 2)
    return imc

imc_ana = calcular_imc(68, 1.72)
imc_luis = calcular_imc(90, 1.80)

print(f"IMC de Ana: {imc_ana:.1f}")
print(f"IMC de Luis: {imc_luis:.1f}")
Parámetro vs. argumento

Parámetro: el nombre dentro de la función (peso). Argumento: el valor real al llamarla (68).

Sin return

Si una función no tiene return, devuelve None.

Parámetros flexibles

Valores por defecto

Un parámetro puede tener un valor de respaldo, para cuando quien llama la función no quiere especificarlo cada vez.

saludo.pypython
def saludar(nombre, idioma="español"):
    if idioma == "español":
        print(f"Hola, {nombre}")
    elif idioma == "inglés":
        print(f"Hello, {nombre}")

saludar("Ana")                # Hola, Ana (usa el valor por defecto)
saludar("John", "inglés")     # Hello, John (lo sobrescribe)

04 · Alcance (scope)

Qué variables existen dónde

Una variable creada dentro de una función es local: desaparece al terminar. Una creada fuera es global: visible en todo el programa.

scope.pypython
contador_global = 0    # variable global

def procesar_pedido():
    total_local = 100   # variable local
    print(total_local)

procesar_pedido()       # imprime 100
print(contador_global)  # funciona: 0
print(total_local)      # ERROR: NameError
Analogía · el casillero, con reglas de acceso

Local es un casillero en un vestidor privado: solo esa función lo ve. Global es un casillero en el pasillo principal: todos lo ven. Esto es encapsulamiento: cada función es una caja cerrada que solo se comunica por sus parámetros y su return.

Mirando adelante · IA y Machine Learning

Por qué esto importa para IA/ML

Cada biblioteca de ML —pandas, scikit-learn, PyTorch— es, en el fondo, un enorme conjunto de funciones ya escritas.

modelo.fit(datos) es exactamente esto

Le pasas argumentos, ejecuta una lógica interna que no reescribes, y te devuelve un resultado con return — igual que calcular_imc(68, 1.72) de hoy.

Los operadores lógicos también reaparecen tal cual: un sistema de recomendación filtra candidatos con reglas como precio < presupuesto and categoria == preferida, la misma estructura del ejemplo de la alberca.

"Entender parámetros, return y scope hoy es lo que te permite leer código ajeno de IA sin sentir que es magia."

05 · Ejemplo práctico

Del pseudocódigo al código real

validador.pypython
def es_valida(contrasena):
    """Devuelve True si cumple las reglas mínimas de seguridad."""
    if len(contrasena) < 8:
        return False
    if contrasena == "12345678":
        return False

    tiene_numero = False
    for caracter in contrasena:
        if caracter.isdigit():
            tiene_numero = True
            break   # ya encontramos un número

    return tiene_numero
Resultadocontrasena9 → válida · 12345678 → inválida
Punto de confusión clásico

Un return True dentro del for terminaría la función entera, no solo el bucle. Se usó break a propósito porque después seguía faltando return tiene_numero.

06 · Segundo ejemplo

Refactorizar el promedio de notas (Semana 2)

Antes había que copiar el bloque if/else por cada estudiante. Ahora, un solo llamado por estudiante.

evaluar_promedio.pypython
def evaluar_promedio(notas):
    """Recibe una lista de notas y devuelve el promedio y si aprobó."""
    promedio = sum(notas) / len(notas)
    aprobado = promedio >= 6.0
    return promedio, aprobado   # una función puede devolver más de un valor

for nombre, notas in [("Ana", [8.5, 7.0, 9.0]), ("Luis", [4.0, 5.5, 5.0])]:
    promedio, aprobado = evaluar_promedio(notas)
    estado = "Aprobado" if aprobado else "Reprobado"
    print(f"{nombre}: promedio {promedio:.2f} — {estado}")

Nota de vigencia técnica · 2026

Núcleo estable del lenguaje, sin partes desactualizadas

def, return, valores por defecto, range(), break/continue y el modelo de scope son estables desde hace más de una década.

Buena práctica moderna: documentar funciones con docstrings ("""texto""")

Es la convención dominante en proyectos reales de IA/ML, y las herramientas de autocompletado e IA la usan para entender tu código.

Antes de seguir

Errores comunes de principiante

  1. 01

    Olvidar el return y esperar que la función "devuelva algo" sola — sin él, el resultado es None.

  2. 02

    Confundir break (corta el bucle entero) con continue (salta solo esta vuelta).

  3. 03

    Usar or cuando la intención lógica era and, o viceversa.

  4. 04

    Intentar usar fuera de una función una variable creada dentro de ella (confundir local con global).

  5. 05

    Escribir range(5) esperando que incluya el 5 — siempre se detiene un número antes.

Respuestaand exige que ambas condiciones sean verdaderas; or solo exige que al menos una lo sea.

02¿Qué imprime range(2, 9, 3) recorrido con un for?

Respuesta2, 5, 8 — empieza en 2, suma de 3 en 3, se detiene antes de llegar o pasar 9.

Respuestabreak termina el bucle por completo de inmediato; continue solo se salta la vuelta actual.

RespuestaParámetro: nombre declarado dentro de la función (def f(x):). Argumento: valor real al llamarla (f(5), aquí 5).
